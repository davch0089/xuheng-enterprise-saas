# ERP 经营驾驶舱

接口：`GET /erp/dashboard?days=30`，权限：`erp.dashboard.view`。

## 数据口径

- 销售净收入、销售成本和毛利：统计周期内已审核销售出库，扣除已审核销售退货。
- 采购净额：已审核采购收货价税合计，扣除已审核采购退货。
- 库存数量和金额：实时库存成本余额，不按统计周期回溯。
- 资金余额：全部启用资金账户的实时余额。
- 应收应付：当前未结开放项目；逾期金额按到期日早于当天判断。
- SKU TOP：按统计周期内销售净收入降序排列。
- 低库存：SKU 在全部仓库的库存总量低于商品最低库存。
- 近效期：未来 30 天内到期且仍有可用数量的批次。

驾驶舱每五分钟自动刷新，也支持 7、30、90 天周期切换。接口为只读聚合查询，不创建快照，也不修改任何业务数据。
