# 商业单据即时收付款

## 适用单据

- 销售出库单：审核时确认应收；填写本次收款后，同时生成销售收款单并核销本单应收。
- 采购入库单：审核时确认应付；填写本次付款后，同时生成采购付款单并核销本单应付。
- 销售/采购订单、调拨、盘点、组装拆卸不直接产生资金流水，因此只使用统一开单界面，不做即时收付款。

## 金额规则

```text
优惠金额 = 单据价税合计 × (100 - 整单折扣率) ÷ 100
折后应结 = 单据价税合计 - 优惠金额 - 抹零金额
往来余额 = 折后应结 - 本次收付款
```

整单折扣率范围为 `0..100`，本次收付款不能超过折后应结。本次金额大于零时必须选择资金账号；结算方式可以为空。

## 审核联动

销售出库审核在同一数据库事务中依次完成库存出库、成本结转、应收确认、收款单生成、资金入账和应收核销。采购入库审核在同一事务中完成库存入库、成本更新、应付确认、付款单生成、资金出账和应付核销。任一步失败，整个审核事务回滚。

自动生成的财务单通过 `linked_receipt_id` 或 `linked_payment_id` 回写业务单。反审核业务单时，系统先反审核并作废自动财务单，再冲回应收/应付、成本和库存，防止出现孤立资金流水。

## API 调用

保存销售出库或采购入库时，在原请求体中增加：

```json
{
  "settlement_discount_rate": 98,
  "rounding_amount": 0.5,
  "current_payment_amount": 100,
  "settlement_method_id": 1,
  "fund_account_id": 1
}
```

仍调用原有新增/修改和审核接口即可，不需要由前端另行调用收款单或付款单接口。财务单详情及资金流水可继续从销售收款、采购付款和资金流水页面查询。
